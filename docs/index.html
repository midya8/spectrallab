01 / GRAPH CHOICE IS NOT GROUND TRUTH

A large gap can still split the wrong shape.

The moons union-3 graph has an adjusted Rand index of 1.000 against the generator labels. The same points with RBF sigma 1.0 have a much larger eigengap but ARI 0.242. The larger gap is not evidence that a graph captures the intended classes. Raw-coordinate k-means also makes the ARI 0.242 split.

Every graph rule was fixed before fitting. No candidate is hidden, and no graph is selected by labels. The default is union-6 for both fixtures, not a learned optimum. ARI uses generator labels after fitting; normalized cut is only comparable as an objective on the same graph. Spectral relaxation plus k-means is not an exact discrete normalized-cut solver.

04 / A RELAXATION IS NOT A DISCRETE OPTIMUM
Every cut. A better answer.
An original seven-vertex weighted graph has only 63 nonempty binary cuts after fixing vertex 0 to cluster 0. Exhaustive rational enumeration finds the exact best normalized cut. The archived spectral relaxation plus 12-restart k-means returns a worse cut. This is a concrete rounding failure, not merely a warning.

05 / ROTATE THE BASIS, KEEP THE SUBSPACE
A sign is not an identity.
Eigenvector signs are arbitrary. Within a fully retained repeated eigenspace, an orthogonal rotation preserves row-normalized distances and k-means geometry. But if a repeated eigenvalue crosses the retained two-dimensional boundary, different valid choices can change that geometry. We refuse a second/third eigenvalue gap at most 1e-10 instead of pretending one basis is uniquely defined.
The moons mutual-3 graph has four disconnected components. A two-dimensional truncation of its four-dimensional zero eigenspace is not unique, so that fit is explicitly refused. No arbitrary cluster labels are shown. This is a limitation of that graph and requested cluster count, not evidence that points should be discarded.
All graph fits use the full fixture. Adding a new point would rebuild the graph and refit the eigensystem. There is no inductive prediction API, density estimate, calibrated uncertainty, causal interpretation, real-world validation or claim that the best displayed synthetic ARI generalizes.
